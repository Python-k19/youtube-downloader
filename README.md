# 🎬 YouTube Downloader — H4CK3R Edition

Стильный YouTube Downloader с авто-обновлением. Скачивай видео 4K и MP3 в один клик.

## ✨ Возможности

- 🎬 Видео: 4K, 2K, 1080p, 720p
- 🎵 Аудио: MP3 до 320 kbps
- 🔄 Авто-обновление yt-dlp и ffmpeg
- 🎨 Хакерский киберпанк интерфейс
